# ONE OUDH — Scents That Define You

A luxury Indian Oudh perfumery showcase built with React, TypeScript, Vite, Tailwind CSS, Three.js, and Lenis.

## Features
- **Ten Oudh Extraits** with Indian provenance (Kannauj, Assam, Mysore, Kashmir, Madurai) and INR (`₹`) pricing
- **Diagonal Bottle Carousel & Star Seal** with interactive **Mechanical Watch Wheel** selector
- **Light & Dark Space Modes** (cream paper aesthetic & cosmic starfield with shooting stars)
- **360° Interactive 3D Flacon Modal** with live gold-foil label engraving
- **Dedicated SHOP Catalogue** with olfactory family filters, `50ml / 100ml` selection, and slide-over bag drawer

## Development
```bash
npm install
npm run dev
```
